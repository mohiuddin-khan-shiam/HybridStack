# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-06-27

### Added
- Initial public release accompanying the paper publication in Array journal.
- Complete HybridStack ensemble implementation (XGBoost + Ridge with Ridge meta-learner).
- 16 baseline model implementations with documentation.
- 32 exploratory data analysis modules with documentation.
- 3 explainability methods (SHAP, LIME, PDP) with documentation.
- 7 regression evaluation metrics with documentation.
- 10 original FRED macroeconomic datasets with documentation.
- Ablation study notebooks.
- Full project pipeline notebook.
- Comprehensive README with reproduction instructions.
- Apache 2.0 license.
- CITATION.cff for automated citation.
- GitHub issue templates and CI workflow.
